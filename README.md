# Для Машеньки ♡

Мобильное приглашение на прогулку с пошаговым выбором еды, времени встречи и сеанса кино.

## Что внутри

- нежный анимированный фон и стеклянная карточка;
- вступление с эффектом печати и звуком клавиш;
- выбор нескольких блюд;
- ползунки времени встречи;
- выбор сеанса «Человека-паука»;
- отправка ответа на почту и персональная итоговая открытка;
- адаптация под современные iPhone и поддержка безопасных зон экрана.

## Локальный запуск

```bash
npm install
cp .env.example .env.local
npm run dev
```

В `.env.local` нужно указать адрес получателя в переменной `RECIPIENT_EMAIL`.

## Проверка

```bash
npm test
```
